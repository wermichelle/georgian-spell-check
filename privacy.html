Privacy Policy

Effective date: November 4, 2026

This policy explains how the Georgian Spell Check plugin for Adobe InDesign (“the plugin”) handles your data. The plugin is published by Wer Michelle (“we”). Contact: wermichelle@gmail.com.

Summary

  • We do not collect, receive or store any of your data. The plugin has no user accounts, analytics or tracking.
  • The dictionary and typography checks run entirely on your computer.
  • Only the optional AI check sends text over the internet: directly from your computer to Anthropic, with your own API key, and only when you click “AI check”.

Data that stays on your computer

  • Document text. The plugin reads the text you choose to check (whole document, current story or selection) and processes it locally.
  • Settings, personal dictionary and AI cache. Stored in the plugin's own data folder on your computer. The AI cache keeps the AI results for paragraphs you have already checked, so they are not sent again. You can clear it in Settings.
  • Anthropic API key. Stored on your computer in the encrypted secure storage that Adobe's plugin runtime (UXP) provides. You can remove it in Settings at any time.

AI check (optional)

When you click “AI check”, the plugin sends the paragraphs that contain Georgian text in the scope you selected to Anthropic's API (api.anthropic.com), using the API key you entered. The request goes directly from your computer to Anthropic; we never receive it. Anthropic processes the text under your agreement with Anthropic and its privacy policy. Do not use the AI check for text that you are not allowed to share with third-party services.

If you never enter an API key or never click “AI check”, no text leaves your computer.

Network access

The plugin declares a single network destination in its manifest: https://api.anthropic.com. When you click “Help & privacy”, it opens this website in your web browser.

This website

This website is hosted on GitHub Pages. GitHub may process technical data such as your IP address when you visit it; see the GitHub Privacy Statement. The website uses no cookies, analytics or tracking of its own.

Children

The plugin is a professional tool and is not directed at children.

Changes

If this policy changes, we will update this page and its effective date.
